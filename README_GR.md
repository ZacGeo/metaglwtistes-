# CPP - Στάδιο 2: Σημασιολογική ανάλυση και ΑΣΔ

Το project αυτό επεκτείνει τον ΛΑ/ΣΑ του Σταδίου 1 με την υποδομή του Σταδίου 2.

## Τι προστέθηκε

- `types.c/.h`: αναπαράσταση βασικών και σύνθετων τύπων, συναρτήσεων και παραμέτρων.
- `ast.c/.h`: Αφηρημένο Συντακτικό Δέντρο (ΑΣΔ), εκτύπωση και αποδέσμευση.
- `semantic.c/.h`: επίλυση αναγνωριστικών, έλεγχοι τύπων, αναθέσεων, κλήσεων,
  επιστροφών, συνθηκών και `break`/`continue`.
- Εμπλουτισμένος `symtab.c/.h`: κατηγορία συμβόλου, τύπος, κατηγορία αποθήκευσης,
  offset και μέγεθος για κάθε εμβέλεια.
- Semantic actions στο `parser.y`, οι οποίες κατασκευάζουν ΑΣΔ παράλληλα με την
  αναγνώριση του προγράμματος.
- Μετατροπές `int <-> float` αποθηκεύονται ρητά ως κόμβοι `CAST` στο ΑΣΔ.
- Εκτύπωση ΑΣΔ και πίνακα χώρου δεδομένων στο τέλος κάθε μονάδας.
- Άμεσος τερματισμός στο πρώτο σημασιολογικό σφάλμα, όπως ζητά η εκφώνηση.

## Build

Linux/WSL:

```bash
sudo apt install build-essential flex bison
make clean
make
make test
```

Windows με WinFlexBison (αν οι εντολές ονομάζονται `win_bison`/`win_flex`):

```powershell
win_bison --defines=parser.tab.h --output=parser.tab.c --verbose parser.y
win_flex --outfile=lex.yy.c lexer.l
gcc -std=c11 -Wall -Wextra -o cpp_stage2.exe parser.tab.c lex.yy.c ast.c types.c semantic.c symtab.c diagnostics.c
```

Εκτέλεση:

```bash
./cpp_stage2 -q tests/valid_scalar.cpp
```

## Πώς λειτουργεί

1. Ο lexer επιστρέφει και το ακριβές κείμενο των τελεστών (`+`, `-`, `==` κλπ.).
2. Κάθε κανόνας έκφρασης δημιουργεί κόμβο ΑΣΔ και υπολογίζει τον τύπο του.
3. Κάθε αναφορά σε `ID` αναζητείται από την εσωτερικότερη προς την εξωτερικότερη
   εμβέλεια. Άγνωστο όνομα είναι σημασιολογικό σφάλμα.
4. Κάθε δήλωση αποθηκεύει στον ΠΣ είδος, τύπο, storage class, offset και μέγεθος.
5. Σε ανάθεση ελέγχεται ότι το αριστερό μέλος είναι lvalue και ότι οι τύποι είναι
   συμβατοί. Για αριθμητική μετατροπή εισάγεται κόμβος `CAST`.
6. Σε κλήση συνάρτησης ελέγχονται πλήθος, τύπος και τρόπος περάσματος παραμέτρων.
7. Τα `return`, `if`, `while`, `for`, `break` και `continue` ελέγχονται με βάση το
   τρέχον function/loop context.

## Σημαντική κατάσταση υλοποίησης

Η υποδομή και ο βασικός σημασιολογικός πυρήνας είναι υλοποιημένα. Πριν θεωρηθεί
οριστική παράδοση ολόκληρης της CPP, πρέπει να ολοκληρωθούν και να δοκιμαστούν με
τα επίσημα αρχεία του eClass οι ειδικοί κανόνες για:

- enum values με υπολογισμό ρητών/αυτόματων τιμών,
- κληρονομικότητα και `private/protected/public`,
- αντιστοίχιση prototype με πλήρη δήλωση μεθόδου `Class::method`,
- `this` και έμμεση αναφορά μελών μέσα σε μέθοδο,
- `CAR/CDR/...` με ακριβή παραγωγή τύπου,
- πλήρη έλεγχο φωλιασμένων initializer lists και εξαγωγή παραλειπόμενης διάστασης,
- σταθερή αποτίμηση εκφράσεων αρχικοποίησης,
- ακριβές layout ανώνυμης ένωσης μέσα σε κλάση.

Αυτά δεν πρέπει να παρουσιαστούν ως ολοκληρωμένα αν δεν ελεγχθούν πάνω στα επίσημα
tests. Το παρόν project είναι ασφαλής, επεκτάσιμη βάση για τη συνέχιση του Σταδίου 2.
